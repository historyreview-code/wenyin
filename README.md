# 玦 · 秦晋之好（长篇连载）

历史长篇小说。以文嬴（玦）的一生为线索：从秦宫少女、质子之妻，到晋文公夫人、晋襄公嫡母，直至秦晋之好破碎。据《左传》《史记》创作。

## 阅读

- 在线阅读：[GitHub Pages](https://historyreview-code.github.io/wenyin/)
- Railway 镜像：[wenyin-production.up.railway.app](https://wenyin-production.up.railway.app/)
- 卷目：卷一·质子之妻 / 卷二·流亡之君 / 卷三·裂痕 / 卷四·崤山（卷五·余烬筹备中）

## 文件

- `崤山_长篇_卷一~四.md` — 分卷文本稿
- `崤山_长篇大纲.md` — 五卷大纲与字数预计
- `build_site.py` — 卷目 HTML 生成器（改稿后运行 `python3 build_site.py`）
