# 玦 · 秦晋之好（长篇·全书完）

历史长篇小说。以文嬴（玦）的一生为线索：从秦宫少女、质子之妻，到晋文公夫人、晋襄公嫡母，直至秦晋之好破碎、她的死。据《左传》《史记》创作。

## 阅读

- Railway 镜像：[wenyin-production.up.railway.app](https://wenyin-production.up.railway.app/)
- 正文生僻字内置注音；另有[难字注音表](https://historyreview-code.github.io/wenyin/zhuyin.html)

|---|---|---|
| 卷一·质子之妻 | 前658—前636 | 楔子（骊姬之乱/重耳流亡）、名字、火（韩原）、屏后、质子、逃与留、匜盥、宴、河水（9章） |
| 卷二·流亡之君 | 前636—前630 | 绛、母亲、弟弟（城濮）、盟单（践土）、旧梦、裂缝、无礼（围郑）（7章） |
| 卷三·裂痕 | 前630—前628 | 名存实亡、伏笔、病（重耳临终）、柩声（4章） |

| 卷五·余烬 | 前627—前616 | 晋太后、无声的偿还、信、令狐、桥（5章） |
